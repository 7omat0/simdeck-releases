# SimDeck

SimDeck은 iOS 시뮬레이터 앱 개발을 돕는 macOS 메뉴 막대 앱이자 명령줄 도구입니다. [English](README.md)

이 저장소에는 SimDeck 배포 파일(DMG)과 업데이트 피드만 있습니다. 소스 코드는 공개하지 않습니다.

## 기능

- **딥링크·푸시**: 시뮬레이터에서 URL과 딥링크를 열고, 앱에 푸시 알림 페이로드를 보냅니다. 앱별로 저장해 다시 쓸 수 있습니다.
- **위치·권한·상태 막대**: 고정 위치·경로·내장 시나리오로 위치를 시뮬레이션하고, 개인정보 보호 권한을 허용·취소·재설정하고, 상태 막대를 덮어씁니다(예: 9:41 프리셋).
- **캡처**: 시뮬레이터 화면의 스크린샷과 화면 기록을 저장합니다.
- **디자인 도구**: 격자, 눈금자와 안내선, 색상 고르기가 되는 돋보기, 디자인 이미지를 앱 위에 겹쳐 보는 비교 기능이 있습니다.
- **Network Monitor**: 패널의 **Network Monitor와 함께 실행**으로 띄운 시뮬레이터 앱, 또는 **Xcode로 실행한 앱 연결**을 켰을 때 Xcode로 실행한 앱의 HTTP 요청을 살펴봅니다. 요청을 cURL로 복사하고 HAR 파일로 내보냅니다. **Map Local**로 요청에 Mac의 JSON 파일로 응답하고, 여러 버전을 바꿔 가며 쓸 수 있습니다.
- **네트워크 프로필**: Mac이나 다른 앱에는 영향을 주지 않고, 고른 시뮬레이터 앱의 네트워크만 제한합니다(비행기 모드, 100% 패킷 손실, 3G, Edge, LTE, Wi-Fi, DSL, 매우 나쁜 네트워크).
- **명령줄 도구**: `simdeck` 명령으로 터미널과 스크립트에서 같은 작업을 합니다(`--json`은 기계가 읽는 출력).
- **에이전트 명령**: `simdeck ui`로 Claude Code 같은 코딩 에이전트가 패널에서 고른 시뮬레이터 앱의 화면을 읽고 조작합니다. 탭, 입력, 스와이프, 스크롤, 기다리기, 시스템 경고 창 응답, 기기 버튼 누르기, 회전, 화면 모드 바꾸기, Face ID 흉내를 할 수 있습니다. 시뮬레이터 안의 XCTest 도우미로 동작하므로 Mac의 마우스 포인터를 움직이거나 키보드 포커스를 가져가지 않습니다.
- **한국어와 영어**: macOS 언어를 따릅니다.

## 요구 사항

- macOS 15 이상
- iOS 시뮬레이터 런타임이 설치된 Xcode
- 에이전트 명령: iOS 18 이상 시뮬레이터

## 설치

1. [Releases](https://github.com/7omat0/simdeck-releases/releases)에서 `SimDeck-<버전>.dmg`를 내려받습니다.
2. DMG를 열고 **SimDeck**을 **응용 프로그램** 폴더로 끌어다 놓습니다. 네트워크 확장 프로그램, 명령줄 도구, 업데이트를 설치하려면 SimDeck이 `/Applications`에서 실행되어야 합니다.
3. 응용 프로그램 폴더에서 SimDeck을 엽니다. 메뉴 막대에 나타납니다.
4. 필요하면 다음을 설정합니다.
   - **네트워크 프로필**: 패널의 네트워크 탭에서 **확장 프로그램 설치…**를 클릭합니다. macOS가 물으면 확장 프로그램을 허용하고(시스템 설정 > 일반 > 로그인 항목 및 확장 프로그램), SimDeck의 네트워크 콘텐츠 필터링을 허용합니다.
   - **디자인 도구**: 시스템 설정 > 개인정보 보호 및 보안 > 손쉬운 사용에서 SimDeck을 허용하면 시뮬레이터 윈도우를 따라갑니다.
   - **명령줄 도구**: SimDeck 설정에서 **명령줄 도구 설치…**를 클릭하면 `/usr/local/bin/simdeck`이 만들어집니다(관리자 암호를 묻습니다).
   - **Claude Code용 에이전트 스킬**: SimDeck 설정 > 에이전트에서 **에이전트 스킬 설치…**를 클릭합니다. 스킬은 `~/.claude/skills/simdeck`에 설치되고 Claude Code에 `simdeck ui` 쓰는 법을 알려 줍니다. 스킬은 `PATH`나 SimDeck.app 안에서 `simdeck`을 찾으므로 명령줄 도구는 없어도 됩니다.
   - **Xcode로 실행한 앱의 Network Monitor 연결**: SimDeck 설정 > Network Monitor에서 **Xcode로 실행한 앱 연결**을 켭니다. SimDeck이 Xcode 중단점 목록의 User에 SimDeck 중단점 하나를 더해, Xcode로 시뮬레이터에 실행한 앱이 코드 수정 없이 Network Monitor에 보입니다. 이 설정은 Xcode를 닫은 채 바꾸세요. Xcode가 열려 있으면 Xcode를 닫은 뒤에 바뀝니다.

## 에이전트 명령 쓰기

1. 시뮬레이터를 부팅하고 SimDeck 패널에서 시뮬레이터와 앱을 고릅니다. 에이전트 명령은 이 선택에만 동작합니다.
2. Claude Code에 앱에서 확인할 일을 요청합니다. 예: "로그인 화면에서 틀린 비밀번호를 넣고 오류 문구가 뜨는지 확인해 줘."
3. 에이전트가 일하는 동안 패널에 에이전트 상태가 보입니다. 시뮬레이터마다 첫 명령이 그 시뮬레이터에 "SimDeck Agent" 도우미 앱을 설치하고 시작합니다.

전체 명령은 `simdeck ui --help`로 볼 수 있습니다.

## 업데이트

SimDeck은 요청할 때만 업데이트를 확인합니다. 패널이나 설정 > 업데이트에서 **업데이트 확인…**을 클릭하세요. 업데이트는 서명·공증되어 있습니다.

## 제거

1. SimDeck 설정에서 **확장 프로그램 제거…**를 클릭하고 요청을 승인합니다. 네트워크 확장 프로그램과 콘텐츠 필터가 함께 지워집니다.
2. SimDeck을 종료하고 응용 프로그램 폴더에서 휴지통으로 옮깁니다.
3. 명령줄 도구를 설치했다면 터미널에서 `sudo rm /usr/local/bin/simdeck`을 실행합니다.
4. 필요하면 `~/Library/Application Support/SimDeck`에 있는 저장한 액션과 네트워크 기록을 지웁니다.
5. 필요하면 에이전트 스킬 폴더 `~/.claude/skills/simdeck`을 지우고, 시뮬레이터에서 "SimDeck Agent" 도우미 앱을 지웁니다(알려진 문제 참고).

**Xcode로 실행한 앱 연결**을 켰다면 2단계 전에 Xcode를 닫은 채 끄세요. 그러지 않았다면 Xcode 중단점 탐색기의 User에서 SimDeck 중단점을 지우면 됩니다.

1단계 없이 휴지통으로 옮겨도 macOS가 네트워크 확장 프로그램 제거를 묻습니다. 다만 시스템 설정 > 네트워크 > 필터에 "SimDeck" 콘텐츠 필터가 남을 수 있으니, 남아 있으면 그곳에서 지우세요.

## 알려진 문제

- 새 네트워크 확장 프로그램이 들어 있는 업데이트 뒤에 "Mac을 재시동해 업데이트를 마치세요."가 보일 수 있습니다. 재시동하면 네트워크 프로필이 다시 동작합니다.
- 에이전트 명령은 Xcode 27.2와 iOS 27 iPhone 시뮬레이터로 만들고 확인했습니다. 다른 Xcode 버전, 더 낮은 iOS 버전, iPad 시뮬레이터에서는 확인하지 않았습니다.
- "SimDeck Agent" 도우미 앱은 에이전트 명령을 쓴 시뮬레이터마다 설치된 채 남고 홈 화면에 보입니다. 지우려면 `xcrun simctl uninstall <시뮬레이터 UDID> com.ohisea.simdeck.agentrunner.xctrunner`를 실행하세요.
- 고른 앱 앞에 다른 앱(홈 화면 아님)이 있으면 에이전트 명령이 시간 상한까지 기다린 뒤 `helper_timed_out`으로 실패할 수 있습니다. 그러면 SimDeck이 도우미를 다시 시작하고, 다음 명령은 정상으로 동작합니다.
- Xcode에서 중단점 전체 끄기(⌘Y) 중에는 Xcode로 실행한 앱이 Network Monitor에 연결되지 않습니다.
- **Xcode로 실행한 앱 연결**로 연결한 앱은 시작 직후의 아주 이른 요청이 Network Monitor에 보이지 않을 수 있습니다.
- Map Local은 URLSession 요청(Alamofire처럼 그 위에서 도는 라이브러리 포함)만 바꿉니다. 웹뷰·백그라운드 세션·소켓은 바뀌지 않습니다. SimDeck을 업데이트하기 전부터 실행 중이던 앱은 다시 실행해야 합니다. Map Local 설정은 파일의 전체 경로를 담으므로 다른 Mac과 나누는 용도가 아닙니다.

## 개인정보

SimDeck은 사용 데이터를 수집하지 않습니다. Network Monitor 기록은 Mac 안에만 있습니다.
